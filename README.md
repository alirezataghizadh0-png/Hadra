# هدرا | تحلیل هوشمند پیج — نسخه اولیه PWA

یک وب‌اپ تک‌صفحه‌ای فارسی و راست‌چین برای ثبت اطلاعات کسب‌وکار، نگهداری محلی تصاویر، ساخت پرامپت اختصاصی، واردکردن گزارش واقعی و آماده‌سازی خروجی چاپی PDF.

## فناوری
- HTML/CSS/JavaScript خام؛ بدون فریم‌ورک و بدون API پولی.
- localStorage برای ذخیره فرم و تصاویر فشرده‌شده روی همان مرورگر.
- Web Share API و Clipboard API در صورت پشتیبانی مرورگر.
- PWA با manifest و service worker برای نصب و استفاده آفلاین پس از بارگذاری اولیه.
- PDF در این نسخه از طریق پنجره چاپ مرورگر تهیه می‌شود؛ فایل PDF باینری مستقیماً توسط JavaScript ساخته نمی‌شود. این انتخاب برای جلوگیری از تولید PDF فارسی با حروف جدا یا ترتیب نادرست است. کیفیت نهایی به موتور چاپ و فونت‌های دستگاه وابسته است و باید روی آیفون آزمایش شود.

## اجرا
سرویس‌دهی از طریق HTTPS یا localhost لازم است تا PWA و Service Worker فعال شوند. برای تست محلی می‌توان در پوشه پروژه اجرا کرد:

```bash
python -m http.server 8000
```

سپس در همان دستگاه `http://localhost:8000` را باز کنید.

## نصب روی آیفون
1. پوشه را روی یک میزبان استاتیک HTTPS که خودتان انتخاب کرده‌اید بارگذاری کنید؛ این نسخه به سرور برنامه یا پایگاه‌داده نیاز ندارد، اما برای بازشدن از اینترنت یک میزبان استاتیک لازم است.
2. لینک را در Safari آیفون باز کنید.
3. Share → Add to Home Screen را بزنید.
4. برای پشتیبان‌گیری از دکمه «خروجی پشتیبان» استفاده کنید.

## حریم خصوصی و محدودیت‌ها
- اطلاعات داخل localStorage همین مرورگر می‌ماند؛ پاک‌کردن داده‌های Safari یا حذف داده‌های سایت ممکن است آن‌ها را حذف کند.
- تصاویر انتخاب‌شده فقط پس از انتخاب کاربر پردازش و به‌صورت کوچک‌شده ذخیره می‌شوند؛ اپ آن‌ها را جایی آپلود نمی‌کند.
- ساخت پرامپت تحلیل واقعی نیست. کاربر باید پرامپت و تصاویر را آگاهانه به سرویس هوش مصنوعی بفرستد.
- گزارش باید از ChatGPT یا تحلیل‌گر دریافت و دستی در فرم وارد شود.
- PDF از طریق Print/Save as PDF تولید می‌شود. روی iOS ممکن است مراحل ذخیره‌سازی با نسخه سیستم‌عامل تفاوت داشته باشد.
- Service Worker و نصب PWA در این بسته هنوز روی دامنه HTTPS واقعی تست نشده‌اند.
